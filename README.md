## ✦ ECOSYSTEM OVERVIEW

**OkzByte** is a Hybrid Exchange & Marketplace that brings digital-asset trading, real-world assets (RWA), property technology (PropTech), investment opportunities, and service marketplaces into one connected ecosystem.

### ◈ The Exchange Engine
Designed for digital-asset discovery, spot trading, launchpad projects, and spot-trading automation.

### ◈ The Marketplace Engine
Focused on real-estate and real-world services, including property buying/selling, renting, installment-based services, and hotel booking.

### ◈ Orakzai Properties
The PropTech arm exploring real-estate tokenization and fractional property ownership through blockchain-based infrastructure.

## ✦ TECH STACK & ARCHITECTURE

- **Runtime:** Node.js 24, TypeScript 5.9
- **API Architecture:** Express 5 with OpenAPI 3.1 Specifications
- **Persistence:** PostgreSQL + Drizzle ORM
- **Validation:** Zod (`zod/v4`)
- **Infrastructure:** pnpm workspaces, esbuild
- **Formal Methods:** TLA+ specifications for state transitions and Coq-verified safety invariants.

## ✦ REPOSITORY MAP

- `lib/api-spec`: OpenAPI definitions and generated Zod schemas.
- `lib/db`: Database schema and Drizzle ORM configurations.
- `artifacts`: Smart contract build outputs and verification data.
- `verification`: Formal verification models and TLA+ specs.
